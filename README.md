# 🧠 Neural Networks From Scratch

Ce projet a pour objectif de comprendre en profondeur le fonctionnement des réseaux de neurones artificiels en les implémentant **from scratch**, sans utiliser de frameworks de deep learning comme TensorFlow ou PyTorch.

L’approche est volontairement progressive : partir des bases mathématiques et algorithmiques pour construire, étape par étape, les composants essentiels d’un réseau de neurones moderne.

---

## 🎯 Objectifs

- Comprendre le fonctionnement d’un neurone artificiel
- Implémenter le produit scalaire et le biais
- Construire des couches de neurones
- Ajouter des fonctions d’activation
- Passer d’implémentations en Python pur à des versions vectorisées avec NumPy
- Comprendre le forward pass
- Préparer la transition vers PyTorch
